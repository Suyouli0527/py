```python
def main():
    word = "ijklmnop"
    s = ""
    length = len(word)
    for i in range(length // 2)
    """range是前闭后开"""
        if i < 2:
            c1 = word[3]
            c2 = word[6-3*i]
        else :
            c1 = word[6*(i-2)]
            c2 = word[7]
        s = s + c1 + c2
    print(s)
main()

```

## 2.列表（用于组织大量数据）
### def:用于记录一组有序数据项的集合

   - 每个数据项称作元素
   - 有序性，允许重复元素
   - 可以根据索引位置访问元素
   - 长度不变
   - 有内置的函数，列表访问更加方便
   - 存放的都是指针

#### 列表操作
- ##### **列表的创建**
     - ` ints = [1024, 996 , 35] `
     - ` strs = ['C++', 'Java' , 'Python' ] `
     - ` mix = [8 , 'hello' , 3.1 , True ] `
     - ` empty_list = [] `

- ##### **访问列表元素**
        ` mix[0] = 10 `(可以改变，可以访问)

- ##### **用列表做参数**
    - 参数传递时传递的是引用而不是值，传递的是列表的地址
    - 再被调用时若改变了列表的值，主调函数中的列表也要改变(此时发生引用传递而不是值传递，`&a`)
    ```python
        def DayDreaming(list) : 
            list[0] = list[0] * 3
            list[1] += 2
            list[2] += 1
        def main() :
            info = [6000, 0 ,0]
            DayDreaming(info)
        main()
    ```

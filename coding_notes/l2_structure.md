6. 位运算

位运算直接对整数的二进制位进行操作。可以使用 `bin()` 查看整数的二进制表示：

```python
print(bin(5))  # 0b101
print(bin(3))  # 0b11
```

常用的位运算符：

| 运算符 | 含义 | 规则 |
| --- | --- | --- |
| `&` | 按位与 | 对应位都为 1 时结果为 1 |
| `|` | 按位或 | 对应位至少有一个为 1 时结果为 1 |
| `^` | 按位异或 | 对应位不同时结果为 1 |
| `~` | 按位取反 | 将每一位取反 |
| `<<` | 左移 | 二进制位向左移动 |
| `>>` | 右移 | 二进制位向右移动 |

例如，`5` 的二进制是 `0101`，`3` 的二进制是 `0011`：

```text
  0101            0101            0101
& 0011          | 0011          ^ 0011
------          ------          ------
  0001            0111            0110
```

因此：

```python
a = 5
b = 3

print(a & b)  # 1，按位与
print(a | b)  # 7，按位或
print(a ^ b)  # 6，按位异或
print(~a)     # -6，按位取反
print(a << 1) # 10，左移一位
print(a >> 1) # 2，右移一位
```

左移 `n` 位通常相当于乘以 `2 ** n`；对于非负整数，右移 `n` 位通常相当于整除 `2 ** n`：

```python
print(5 << 2)  # 20，即 5 * 2**2
print(5 >> 1)  # 2，即 5 // 2
```

位运算的常用技巧：

```python
n = 7

# 二进制末位是 1 表示奇数，末位是 0 表示偶数
if n & 1:
    print("奇数")
else:
    print("偶数")

# 一个数与自身异或的结果为 0
print(n ^ n)  # 0

# 一个数与 0 异或后保持不变
print(n ^ 0)  # 7
```

Python 中按位取反满足 `~x == -x - 1`，所以 `~5` 的结果是 `-6`。

# Markdown 语法速查表

> 本文件记录 Markdown 的常用语法，方便写课程笔记时随时翻阅。
> 原则：块级元素（标题、列表、代码块、引用）之间留一个空行，能避免绝大多数解析歧义。

## 1. 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

`#` 的数量代表级别，最多 6 级，注意 `#` 后要有一个空格。

另一种写法（下划线式，只支持两级）：

```markdown
一级标题
=======

二级标题
-------
```

## 2. 强调

```markdown
*斜体* 或 _斜体_
**粗体** 或 __粗体__
***粗斜体***
~~删除线~~
`行内代码`
```

效果：*斜体*、**粗体**、***粗斜体***、~~删除线~~、`行内代码`

## 3. 列表

```markdown
- 无序项
- 无序项
  - 缩进两个空格表示嵌套
    - 再嵌套一层

1. 有序项
2. 有序项
3. 有序项

- [ ] 未完成任务
- [x] 已完成任务
```

无序列表的符号 `-`、`*`、`+` 都可以，但同一列表里最好统一。嵌套靠缩进（2 或 4 个空格）实现。

## 4. 链接与图片

```markdown
[链接文字](https://example.com)
[带标题的链接](https://example.com "鼠标悬停显示的文字")
<https://自动识别为链接.com>

![图片描述](image.png)
![图片](https://example.com/a.png "图片标题")

[引用式链接][1]
[1]: https://example.com
```

`!` 是图片和链接的唯一区别。图片方括号里是 alt 文字（图片加载失败时显示）。

## 5. 代码

行内代码用反引号：

```markdown
`print("hello")`
```

代码块用三个反引号包裹（下面外层用四个反引号才能嵌套显示），并指定语言以获得高亮：

````markdown
```python
def add(a, b):
    return a + b
```
````

语言标签可写 `python`、`javascript`、`bash`、`json`、`text` 等。写 Python 笔记时始终标注 `python`，高亮后读代码快很多。

## 6. 引用

```markdown
> 这是一段引用
> 可以跨多行

> 嵌套引用
>> 第二层
```

## 7. 分隔线

```markdown
---
***
___
```

三个以上连续的 `-`、`*` 或 `_`。注意 `---` 单独一行时也可能被当作标题下划线，前面留空行更保险。

## 8. 表格

```markdown
| 语法 | 说明 | 示例 |
| :--- | :---: | ---: |
| 左对齐 | 居中 | 右对齐 |
| `#` | 标题 | `# 标题` |
```

第二行的冒号控制对齐：`:---` 左对齐、`:---:` 居中、`---:` 右对齐。

## 9. 转义与换行

```markdown
\* 不是斜体 \*
\\ 反斜杠
\` 不是代码 \`

行尾加两个空格  
强制换行（或直接空一行分段）
```

需要显示 Markdown 符号本身时，在前面加反斜杠。

## 10. 扩展语法（取决于渲染器）

GitHub、Typora、Obsidian、VS Code 预览等支持，标准 Markdown 不一定支持：

```markdown
脚注引用[^1]
[^1]: 脚注内容

$$E = mc^2$$        数学公式（KaTeX / MathJax）

:smile:             Emoji 短代码

术语
: 定义列表（部分渲染器）

<!-- HTML 注释，不显示 -->

<details>
<summary>可折叠内容</summary>
里面的文字默认隐藏
</details>
```

也可以直接嵌入 HTML，比如 `<br>`、`<img width="300">`、`<sub>` 等。

## 11. 实践建议

1. **空行分隔**：块级元素之间留空行，解析最稳。
2. **中英文混排**：中文和英文/数字之间加一个空格，阅读体验更好。
3. **代码块标语言**：Python 笔记一律写 ` ```python `。
4. **标题层级不要跳**：`#` → `##` → `###`，方便生成目录和导航。
5. **列表编号用 `1.` 开头即可**：渲染器会自动编号，不必手写 1/2/3（本文件手写是为了源码可读）。
